# 常见坑

## 文本发现

- **只查 `TextAsset`**：大量文本在 MonoBehaviour、StringTable、AssetBundle、代码或图片中。
- **混淆内部名和玩家文本**：对象名、动画名、着色器名、调试日志常被误翻译。
- **忽略动态拼接**：组件默认值是空的，真正文本在代码或数据表里。
- **忽略上下文**：同一短词在不同场景需要不同译文。
- **遗漏重复来源**：同一文本可能被多个场景、bundle 或 fallback 引用。

## 结构与资产

- **类型树不匹配**：Unity 版本、序列化字段和工具版本不一致会导致错误读写字段。
- **AssetBundle 依赖被破坏**：只改一个 bundle，不更新 catalog/依赖，可能加载失败。
- **序列化漂移**：读写工具可能重排字段或改变字节；必须做原样往返测试。
- **编码误判**：不要默认 UTF-8；检测编码后再解码。
- **占位符破坏**：标签、参数、分隔符、换行丢失后，UI 或剧情逻辑会异常。

## 翻译

- **术语子串污染**：短词替换会破坏长词，应最长匹配优先。
- **模型泄漏 prompt**：输出包含说明、代码块或原文回显。
- **模型截断**：长文本生成不收敛，应停止重试并拆段或人工处理。
- **术语漂移**：分段重译时人名或术语被改写，需要二次校验。
- **过度机翻**：短 UI 标签和剧情文本需要不同质量门槛。

## 字体与 UI

- **缺字变成方框**：目标字体必须覆盖全部译文，包括标点、符号和扩展字符。
- **TMP 动态字体失败**：不同 Unity 版本和运行时对字体创建重载行为不同，需要逐路径验证并记录可用方案。
- **只换字体不改布局**：目标语言更宽或更窄时会溢出、换行异常或截断。
- **忽略粗斜体和 fallback**：单一字体资产可能不足以覆盖全部 UI 状态。

## 运行时 Hook

- **Hook 点过低**：直接改底层字符串会破坏比较、存档、状态机或打字机效果。
- **字典冲突**：不同上下文同文异译会被精确字典覆盖。
- **加载器冲突**：多个插件同时替换字体或文本会造成顺序问题。
- **异常未处理**：Hook 抛错会导致 UI 崩溃，必须有安全回退。

## 流程与交付

- **覆盖原目录**：所有修改必须进入 overlay 或隔离副本。
- **验证夸大**：冒烟通过不等于全流程验证。
- **游戏更新失效**：记录构建哈希，更新后按语料 ID 做增量比对。
- **隐私泄露**：敏感文本未经许可不得上传。
- **跨 Agent 假设**：不要绑定某个宿主的私有 API；使用通用文件、Shell、代码和 Git 能力。
